System Architecture & Design Signals

Built specifically to prove production readiness in the 90-second technical scan.

Dual-Index Retrieval

Dense Qdrant + Lexical BM25

Overcomes vocabulary mismatch by searching vector representations and exact keyword tokens in parallel.

Rank Fusion

Reciprocal Rank Fusion (RRF)

Combines disparate scoring scales using standard constant k=60 without requiring ad-hoc score normalization.

Precision Stage

Cross-Encoder Re-ranking

Filters top-20 candidate pool down to top-5 high-signal chunks, reducing context window noise and token costs.

Guardrail

Hallucination & Citation Guard

Validates footnote quote substrings programmatically against retrieved chunks, rejecting ungrounded claims.
